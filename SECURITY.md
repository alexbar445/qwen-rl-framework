# Security policy

Report suspected vulnerabilities in the framework, its deployment code, or its release artifacts through GitHub's private vulnerability reporting feature when it is enabled for this repository. If that feature is unavailable, contact the maintainers through a private channel published by the repository before sharing exploit details.

Do not put credentials, private model or dataset links, cluster endpoints, or exploitable details in a public issue. Include the affected revision, component, impact, and a minimal reproduction that does not expose secrets.

This project does not publish a response-time or supported-version commitment yet. Check the release notes for the current support scope.
